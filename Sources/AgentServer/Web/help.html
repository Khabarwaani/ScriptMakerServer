HTTP API help

Current implementation: input page, help page and health snapshot. Execution returns HTTP 501. Registry, providers, validation, tracking and cancellation are planned Version 1 features.

Start and stop

Open AgentServer.xcworkspace in Xcode, select the AgentServer scheme and My Mac, then press Command-R. Open http://127.0.0.1:8080/. Stop with Xcode's Stop button.

swift package resolve
swift build
swift test
swift run AgentServer

For terminal runs, stop with Control-C. Configure AGENT_SERVER_PORT and AGENT_SERVER_AGENTS_DIR before startup. The service binds only to loopback.

Execution request schema

Send Content-Type: application/json and Accept: text/event-stream. Provider readiness is checked before execution. Omit version for the highest stable SemVer; explicitly supply a prerelease to use it.

{
  "type": "object",
  "required": ["agent_id", "provider", "input"],
  "properties": {
    "agent_id": {"type": "string", "minLength": 1},
    "version": {"type": "string", "description": "Exact semantic version; optional"},
    "provider": {"type": "string", "description": "Configured provider ID"},
    "input": {"type": "object", "description": "Agent-specific JSON data"}
  }
}

The server must not assume topic/language fields for all agents. Arrays, nested objects, numbers, booleans and null may occur inside the input object. The selected agent may define an input schema; every agent defines a final output schema.

curl -N -X POST http://127.0.0.1:8080/execute \
  -H 'Content-Type: application/json' \
  -H 'Accept: text/event-stream' \
  -d '{"agent_id":"NewsResearcher","version":"1.0.0","provider":"codex","input":{"topic":"Semiconductors","language":"English"}}'

Discovery and status response shapes

{"agents":[{"id":"NewsResearcher","versions":["1.0.0","1.1.0"],"latest":"1.1.0"}]}

{
  "status":"healthy",
  "server":{"version":"1.0.0","uptime_seconds":3600},
  "active_executions":1,
  "executions":[{
    "execution_id":"exec_001","agent_id":"NewsResearcher",
    "version":"1.1.0","provider":"codex","status":"running",
    "streaming":true,"started_at":"2026-10-12T06:00:00Z"
  }]
}

Execution states: queued, running, cancelling, cancelled, completed and failed. Status must never reveal input, prompts or credentials. Terminal records are retained temporarily for monitoring.

SSE contract and final result

Response type: text/event-stream. The accepted execution ID appears in X-Execution-ID, the first event and status records. Each event has a JSON data payload. Preserve order within each execution.

event: started
data: {"execution_id":"exec_001","agent_id":"NewsResearcher","version":"1.0.0","provider":"codex"}

event: output
data: {"execution_id":"exec_001","text":"Checking sources..."}

event: result
data: {"execution_id":"exec_001","result":{"summary":"Research complete","findings":[]}}

event: completed
data: {"execution_id":"exec_001"}

Other events: status (progress), failed (structured error) and cancelled (confirmed termination). Only valid final JSON that passes the selected output schema produces result and completed. Intermediate output is not a final result. Disconnecting continues execution by default; there is no resumable stream.

Cancellation

curl -X POST http://127.0.0.1:8080/executions/exec_001/cancel

{"execution_id":"exec_001","status":"cancelling"}

Repeated cancellation is safe. Cancellation applies only to the identified process. Track cancelling until termination is confirmed or a terminal cancellation failure is recorded. Close the associated stream and release resources.

Errors

{"error":{"code":"output_schema_validation_failed","message":"The final result does not match the agent output schema.","execution_id":"exec_001"}}

Execution ID is included when assigned. Required error categories include invalid request JSON, missing fields, unknown agent/version/execution, invalid definition, unavailable provider, initialization or launch failure, timeout, provider failure, invalid final JSON, schema failure, cancellation failure and internal error. Before streaming use an HTTP error response; after streaming emit failed and close the stream. Never include credentials or private configuration.

Define an agent

Agents/AgentID/1.0.0/role.md
Agents/AgentID/1.0.0/instructions.md
Agents/AgentID/1.0.0/output.schema.json

Role describes responsibility in a complete sentence. Instructions define workflow and constraints. Output schema defines final JSON. Published versions are immutable: add another SemVer directory to change behavior. Runtime discovery must not require rebuilding the package.
